# Лабораторная работа №2
## Курс: Киберфизические системы
### Тема: Базовый инференс LLM через Ollama HTTP API

## Описание работы

В данной лаборатоной работе реализован простой сценарий инференса LLM с помощью поднятого **Ollama** сервера.

В качестве модели использована **Qwen2.5:0.5b**.  
Сервер поднят локально и принимает HTTP-запросы. Python-скрипт отправляет на него набор пользовательских запросов и сохраняет ответ модели в CSV-отчёт.

## Что было выполнено

В рамках лабораторной работы были выполнены следующие шаги:
- установка `ollama`;
- загрузка модели `Qwen2.5:0.5b`;
- запуск локального Ollama-сервера;
- написание Python-скрипта для отправки запросов через HTTP API;
- прогон скрипта на 10 произвольных запросах и фиксирование вывода LLM;
- формирование отчёта инференса в формате CSV.

## Используемый стек

- Ollama

- `script.py` — основной Python-скрипт для отправки запросов к Ollama

## Требования

Для запуска потребуется:
- Linux
- Python 3.10+
- установленный Ollama
- доступ к локальному HTTP API Ollama

## Установка и запуск

### 1. Установка Ollama

Установить Ollama командой:
- для arch linux:   

`sudo pacman -S ollama`

- для других дистрибутивов:

`curl -fsSL https://ollama.com/install.sh | sh`


### 2. Загрузка модели

Скачать модель:

`ollama pull qwen2.5:0.5b`

### 3. Запуск сервера Ollama

В отдельном терминале выполнить:

`ollama serve`

Или через systemd:

`sudo systemctl start ollama`

После запуска сервер будет слушать запросы по адресу:

`http://127.0.0.1:11434`

### 4. Подготовка Python-окружения

Создать виртуальное окружение:

`python3 -m venv .venv`

Активировать окружение:

Для Linux:
`source .venv/bin/activate`

Установить зависимости:

`pip install -r requirements.txt`

### 5. Запуск скрипта инференса

Выполнить:

`python3 script.py`

После выполнения будет создан файл:

`inference_report.csv`


### 6. Выключение сервера Ollama

Если сервер Ollama был запущен черз systemd, то нужно прописать

`sudo systemctl stop ollama`

Иначе прописать 

`pkill ollama`


## Пример используемых запросов
